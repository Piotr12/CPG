# qa-evidence

Screenshots and mockups that the om-* skills attach to pull request comments
(`attach-image-evidence` in `.ai/trackers/github.md`). Each folder is one
evidence slug, e.g. `pr-29/` or `spec-admin-sign-in/`, and PR comments link
to the files here through `raw.githubusercontent.com`.

This is an orphan branch: it shares no history with `main` and holds only
images. **Keep it.** Deleting it, or a folder in it, breaks the images in old
PR comments. The repository is public, so evidence must only ever show demo
data.
