## Goal

Any signed-in account runs MRP for every location of a tenant from a new MRP page or a keyed `POST`. The run and the latest run's daily results are stored in one transaction. The page and a `GET` show the latest run. A read-only tenant or a stale Test generation refuses a run, and a Test reset clears Test's runs.
