# lessons

Long-form write-ups of lessons learned by AI agents — findings, root-cause analyses after fixing a bug, pitfalls, and improvements worth keeping in long-term memory.

- [`../lessons.md`](../lessons.md) is the index: one short bullet per lesson. Agents read it at the start of every task.
- When a lesson needs more than a couple of sentences, it gets its own file here, linked from its bullet in `lessons.md`.
- **Naming:** `YYYY-MM-DD-slug.md`, e.g. `2026-10-17-kamal-healthcheck-path.md`.

See [`AGENTS.md`](../../AGENTS.md) for the rules agents follow.
