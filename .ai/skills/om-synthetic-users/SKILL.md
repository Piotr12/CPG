# om-synthetic-users — CPG override

Extends the installed `om-synthetic-users`. Everything not listed here applies unchanged.

**The stamp** is the creation time in UTC with the minute: `STAMP=$(date -u +%Y-%m-%d--%H%MUTC)` → `2026-10-17--1432UTC`. It is the repo naming convention from AGENTS.md (see `.ai/skills/README.md`).

## Walkthrough sessions (`references/session-artifacts.md`)

Name session folders `${research}/walkthroughs/<stamp>-<flow-slug>-session-<NNN>/`. Dates written inside reports and persona files stay plain `YYYY-MM-DD`.
